# VISTA O MOMENTO DE NALOGES

Loja virtual demonstrativa de moda, feita com HTML, CSS e JavaScript.

## Acessar

Quando a publicação do GitHub Pages terminar, a loja ficará disponível em:

https://17042009.github.io/meu-projeto/

A área administrativa de demonstração fica em `/admin.html`.

## Importante

Esta versão é uma demonstração estática. Ela não processa pagamentos, não valida
login no servidor e salva pedidos somente no navegador em que foram feitos.
Não use dados bancários, senhas ou informações pessoais reais no checkout.
